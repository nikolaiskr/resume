# Портфолио Николая Скринника

Многостраничный статический сайт-портфолио: главная, проекты, опыт и контакты. Не требует сборки или сервера.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`.
4. Сохраните настройки. Через пару минут сайт появится по адресу, указанному GitHub.

Проекты пока ведут на общий профиль GitHub `nikolaiskr`; при наличии точных ссылок на репозитории их можно поставить в `projects.html`.
